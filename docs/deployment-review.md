# Runtime 测试部署审查

审查日期：2026-10-12。执行主体为本项目部署脚本与测试程序；被测系统为独立 AgentCore Runtime 和本项目 SDK／适配程序。

本项目是客户端库及确定性 Runtime 适配包。开发者采用官方 Python CodeZip 部署路径，不增加模型、WebUI、Cognito、Gateway 或门户组件。

- 部署脚本只创建名称带本次随机后缀的新 Runtime、工件桶和执行角色；部署脚本把资源标识写入本项目 state 文件。
- Runtime 保持默认 IAM SigV4 入站认证；部署脚本不发布匿名 HTTP 入口、不设置 EC2 入站规则。
- 部署脚本阻止 S3 公共访问并启用服务端加密。执行角色仅可读取本次桶的 code 前缀、写入本次 Runtime 命名前缀下的日志；策略没有全局 `Resource: "*"` 或模型调用权限。
- 执行角色的信任策略限制服务主体、账户及 AgentCore 地区 ARN；执行角色的数据权限仍限制在本项目资源。客户应用仍负责会话归属；SDK 不把 SessionRef 当作授权凭证。
- 适配程序不记录请求正文；测试程序仅提交非秘密内容。部署脚本不在源代码、state 或日志中保存 AWS／E2B 凭证。
- 部署脚本将 idle timeout 设为 60 秒、max lifetime 设为 600 秒。测试程序在 finally 中停止自己创建的 Session，清理脚本只处理 state 记录的项目资源。
- 本地测试已经覆盖文件路径边界、符号链接、请求／响应上限、环境代际检查、流错误、超时和不重放。真实云环境结果由独立测试报告记录。

代码包中的 HTTP 服务依赖 Runtime 提供入站鉴权。本地服务默认监听 127.0.0.1；部署入口在 Runtime 隔离环境中监听 0.0.0.0:8080。开发者不能把该无独立身份认证的 HTTP 服务直接开放给不可信网络。
