# 首版验收标准与测试用例

版本：0.1.0；日期：2026-10-12。开发者在本项目实现同步 Python SDK、Runtime 适配程序和测试工具。开发者采用自定义 Runtime 应用承载确定性操作，不引入模型或 Harness 编排。

测试程序是执行主体；客户端 SDK、容器适配程序、AgentCore Runtime 服务及 E2B 服务是不同的被测组件。测试报告必须分别记录本地、真实 AgentCore 和真实 E2B 的结果。测试程序因凭证缺失跳过的测试不能计入通过。

## 验收门槛

| 编号 | 测试程序执行的操作 | SDK／适配程序必须满足的结果 |
|---|---|---|
| AC-01 | 测试程序创建会话、写 Python 文件、执行并读取结果 | SDK 返回 stdout、stderr、exit_code，文件与命令使用同一会话 |
| AC-02 | 测试程序读取 Unicode 文本、二进制并列目录 | SDK 返回 str／bytearray、WriteInfo 和真实 EntryInfo 属性 |
| AC-03 | 测试程序执行退出码 7 的命令 | SDK 抛出 CommandExitException 并保留输出及退出码 |
| AC-04 | 测试程序注入断流、流内异常、缺少或重复终止事件 | SDK 不返回成功、不重放命令，错误保留部分输出 |
| AC-05 | 测试程序执行无输出命令并设置短等待期限 | SDK 在有界时间内结束等待，声明远端状态未知 |
| AC-06 | 测试程序触发 Runtime 执行期限 | SDK 区分执行超时与等待超时，不伪造退出码 |
| AC-07 | 测试程序使容器启动标识变化后复用旧引用 | 文件处理程序与命令助手拒绝旧标识，客户命令不执行 |
| AC-08 | 测试程序请求 stop，并模拟响应丢失后重试 | SDK 复用 clientToken，区分 STOP_UNKNOWN 与 STOP_REQUESTED |
| AC-09 | 测试程序关闭本地对象 | SDK 关闭本地资源但不隐式调用远端 stop |
| AC-10 | 测试程序传入 TTL、后台运行、PTY 等未支持能力 | SDK 在发出网络请求前明确拒绝 |
| AC-11 | 测试程序访问越界路径、符号链接、超限文件、非空目录 | 适配程序按公开限制拒绝请求，不静默修改其他路径 |
| AC-12 | 测试程序注入初始化响应丢失 | SDK 返回可恢复的 CreateAttempt，不分配新 Session ID 重试 |
| AC-13 | 测试程序并发或重入访问同一 Session | SDK 阻止同 client 内冲突，不混用引用或配置 |
| AC-14 | 测试程序向真实 Runtime 发送 SDK 请求 | AWS SDK 签名、Runtime 路由、适配程序与命令事件解析实际连通 |
| AC-15 | 测试程序向真实 E2B 执行公共能力子集 | 测试程序记录实际 SDK 版本、结果与清理状态；缺凭证必须标为 skipped |
| AC-16 | 测试程序从不同初始目录、无应用环境变量、root 命令入口执行 | SDK 显式传递部署路径；助手按 Boot 文件 owner 降权，与 HTTP 文件操作使用同一身份 |

首版“本地功能通过”要求 AC-01 至 AC-13、AC-16 的相关测试通过；“AgentCore 实测通过”额外要求 AC-14；“E2B 双后端对照通过”额外要求 AC-15。报告不得用其中一种结果替代另一种。SDK 的完整 E2B 替代能力不属于本次验收目标。

## 关键测试步骤

1. 测试程序通过 files.write 写入包含 Unicode 的 Python 文件，再通过 commands.run 执行并断言输出；测试程序继续读取文件和列目录。
2. 测试程序分别执行 stdout、stderr 和非零退出命令，断言回调拼接结果与异常字段。
3. 故障注入程序模拟缺失协议头、错误请求 ID、旧 boot ID、流异常及提前 EOF，检查 SDK 从未报告成功。
4. 测试程序分别设置短客户端等待期限和短服务执行期限，检查两种异常及结果未知标记；测试程序不将断开网络等同于杀死进程。
5. 测试程序重复初始化同一会话，检查适配程序没有清空工作区；测试程序重新启动适配程序后检查旧引用失效。
6. 测试程序模拟第一次 stop 丢失响应，检查第二次请求携带同一 token；测试程序检查 close 没有发出停止请求。
7. 文件测试程序检查 UTF-8、任意字节、覆盖写入、目录已存在、缺失文件、非空目录、符号链接与大小上限。
8. 真实环境测试程序为本次任务分配新会话，仅删除本次创建的资源；测试程序在 finally 中请求停止／销毁并记录清理结果。

## 测试约束

测试程序使用 `TMPDIR` 或项目 `.tmp` 目录保存工作文件。测试程序不打印密钥或文件秘密。真实 E2B 用例需要用户自有 E2B 账户凭证；本地假响应仅用于稳定覆盖故障边界，不能证明云服务行为。客户应用仍负责用户到 SessionRef 的授权及跨进程协调。
